# research-skills

Claude Code skills for investment research.

## earnings-analysis

Analyzes a company's latest quarterly results and writes the report in Traditional Chinese.

```
/earnings-analysis DAL
/earnings-analysis DAL UAL AAL   # analyzes companies in parallel, one report file each
```

- Skill files: `.claude/skills/earnings-analysis/`
- Using it in claude.ai chat: zip the `earnings-analysis` folder and upload it under Settings → Capabilities → Skills.
